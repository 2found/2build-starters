# __PROJECT_NAME__

Next.js web app created with 2build starters. Read [AGENTS.md](AGENTS.md) before
changing code. Requires Node.js 22+ and pnpm 10+. No backend, database or secret is
required to run it.

```bash
pnpm install --frozen-lockfile
pnpm dev
```

The app defaults to http://localhost:3100. `API_URL` points `apiFetch` at a backend
(default `http://localhost:3000`); copy `.env.example` to `.env.local` to change it.

```bash
pnpm run lint
pnpm run typecheck
pnpm test
pnpm run build
pnpm start
```

Stop the dev server before `start`; both use the same port. Architecture lives in
[docs/ARCHITECT-WEB.md](docs/ARCHITECT-WEB.md), visual rules in
[DESIGN.md](DESIGN.md), verification in [docs/VERIFY.md](docs/VERIFY.md).

Framework files were generated by `create-next-app` at bootstrap time; the starter
overlays its harness and app shell on top. Starter source/version:
`.babysit/starter.lock.yaml`. `bbs starter check --json` reports newer relevant
releases without changing this project. Dependency updates are reviewed separately
through package.json and pnpm-lock.yaml.
